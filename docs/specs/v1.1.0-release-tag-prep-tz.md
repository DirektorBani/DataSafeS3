## 2. Scope freeze

### 2.1 Option B (default для этого TZ)

**В тег v1.1.0 входит:**

- C01–C21 из trust-debt TZ (уже в `CHANGELOG [Unreleased]`)
- HA v2 CE: erasure backend, leader lock, site replication, lab compose + `scripts/ha/*`, migrations 013–016
- Console: Teams, MFA wizard, cluster/site-replication pages (если есть в tree)

**Формулировка для operators (обязательна в docs):**

> HA v2 в v1.1.0 — **CE lab foundation** (compose scripts, separate ports). Не production petabyte multi-AZ, не auto-failover orchestrator, не Patroni. Production erasure 4+2 — Phase 4 / future.

**Где зафиксировать:** `CHANGELOG.md` §1.1.0 intro, `project-status.md`, `scaling.md` EN/RU (disclaimer), `ha-replication-v2-tz.md` §11 checklist.

### 2.2 Option A (fallback, только по указанию пользователя)

- v1.1.0 = trust-debt only
- **Исключить из commit:** `internal/ha/`, erasure backend, site replication handlers, migrations 014–016, HA compose, `scripts/ha/*`, cluster UI
- Убрать блок «HA v2» из CHANGELOG §1.1.0 → перенести в `[Unreleased]` или «planned 1.2.0»
