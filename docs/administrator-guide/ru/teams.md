# Команды

Команды позволяют администраторам группировать пользователей для ownership, назначения в консоли и будущих collaboration workflows.

## Консоль

Откройте **Admin → Teams**, чтобы:

1. Создать команду с отображаемым именем.
2. Добавить или удалить участников.
3. Назначить пользователя в команду из управления пользователями.

## API

Admin API предоставляет:

| Операция | Path |
|----------|------|
| Список команд | `GET /api/v1/teams` |
| Создать команду | `POST /api/v1/teams` |
| Обновить команду | `PUT /api/v1/teams/{id}` |
| Удалить команду | `DELETE /api/v1/teams/{id}` |
| Управление участниками | `GET/POST/DELETE /api/v1/teams/{id}/members` |

Все routes требуют JWT администратора. Схемы см. в `docs/api/openapi-full.yaml`.
