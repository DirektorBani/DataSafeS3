# Was ist DataSafeS3?

**DataSafeS3** ist eine selbst gehostete Speicherplattform für sichere und kontrollierte Datenverwaltung.

Sie vereint **S3-kompatiblen Objektspeicher**, eine **Web-Konsole**, **Enterprise-Authentifizierung** (LDAP, SSO, MFA) und **Betriebswerkzeuge** (Audit, Quotas, Monitoring) auf Infrastruktur, die Ihre Organisation selbst betreibt.

## Für wen?

| Zielgruppe | Typischer Bedarf |
|------------|------------------|
| IT-Administratoren | Benutzer, Mandanten, Richtlinien und Audit zentral verwalten |
| Plattform-Teams | S3-Speicher für Kubernetes, CI/CD und interne Apps bereitstellen |
| Sicherheitsteams | Daten und Logs on-prem oder in gewählten Regionen halten |

## Kernfunktionen

- S3-kompatible API (SigV4) für bestehende Tools und SDKs
- Web-Konsole für Buckets, Dateien, Freigaben und Einstellungen
- Multi-Tenancy, Teams und feingranulare Zugriffsrechte
- Prometheus-Metriken und Grafana-Dashboards im Lieferumfang
