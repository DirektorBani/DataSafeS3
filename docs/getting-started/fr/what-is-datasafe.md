# Qu’est-ce que DataSafeS3 ?

**DataSafeS3** est une plateforme de stockage auto-hébergée pour une gestion des données sécurisée et gouvernée.

Elle combine un **stockage d’objets compatible S3**, une **console web**, l’**authentification d’entreprise** (LDAP, SSO, MFA) et des **outils d’exploitation** (audit, quotas, supervision) sur une infrastructure que vous contrôlez.

## Pour qui ?

| Public | Besoin typique |
|--------|----------------|
| Administrateurs IT | Gouverner utilisateurs, locataires, politiques et audit |
| Équipes plateforme | Offrir du stockage S3 à Kubernetes, CI/CD et applications internes |
| Équipes sécurité | Garder données et journaux on-prem ou dans des régions choisies |

## Capacités clés

- API compatible S3 (SigV4) pour outils et SDK existants
- Console web pour buckets, fichiers, partages et paramètres
- Multi-tenant, équipes et droits d’accès fins
- Métriques Prometheus et tableaux de bord Grafana inclus
