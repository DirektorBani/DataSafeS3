# Глоссарий

Термины ниже используются в русских документах DataSafeS3. Английское слово в интерфейсе, API и переменных окружения не переводится.

| English | Русский | Комментарий |
|---------|---------|-------------|
| bucket | бакет | Контейнер объектов. Не «корзина». |
| object | объект | Файл и его метаданные внутри бакета. |
| prefix | префикс | Общий начальный фрагмент ключа, аналог папки в ключе. |
| key | ключ | Имя объекта в бакете. Ключ доступа — отдельно, access key. |
| access key | ключ доступа | Пара для подписи SigV4. Секрет к нему — secret key. |
| tenant | арендатор | Изолированная область пользователей и бакетов. |
| object lock | блокировка объекта | Режим WORM: GOVERNANCE или COMPLIANCE. |
| retention | срок хранения | До какой даты объект нельзя удалить по правилам блокировки. |
| legal hold | юридическое удержание | Флаг, который запрещает удаление, пока его не снимут. |
| versioning | версионирование | Хранение нескольких версий ключа и маркеров удаления. |
| delete marker | маркер удаления | Версия, которая скрывает текущий объект, не стирая прежние версии. |
| lifecycle | жизненный цикл объектов | Правила истечения по префиксу. Не путать с жизненным циклом самого ПО. |
| multipart upload | составная загрузка | Загрузка объекта частями. |
| presigned URL | предподписанная ссылка | Временная ссылка с подписью SigV4. |
| gateway | шлюз репликации | Копирование в другое S3-совместимое хранилище. |
| webhook | вебхук | HTTP-приёмник событий. Необязателен. |
| outbox | очередь исходящих событий | Запись о событии в метаданных до подтверждённой доставки. |
| metadata | метаданные | Учёт бакетов, пользователей и объектов. Bolt или PostgreSQL. |
| one node | один узел | Один процесс, свои байты, по умолчанию Bolt. |
| cluster | кластер | Несколько узлов с общими метаданными PostgreSQL. Это не автоматический multi-AZ. |
| console | веб-консоль | Интерфейс на русском и английском. |

Имена переменных (`STORAGE_*`), путей API и кодов ошибок остаются как в программе.
