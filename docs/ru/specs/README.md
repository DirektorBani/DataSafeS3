# Указатель публичных спецификаций

English: [specs/README.md](../../specs/README.md).

Внутренние ТЗ, отчёты QA и черновики стратегии лежат в `D:\datasafe_tz\` и в этот git не входят.

Публичная документация для человека, который ставит и эксплуатирует продукт, — в `docs/`: начало работы, эксплуатация, руководство администратора, руководство пользователя, журнал изменений.

Архитектурные решения, которые едут вместе с продуктом: [ADR](../architecture/adr/README.md).

Тексты ТЗ, которые есть в дереве на русском, лежат в этом каталоге (`docs/ru/specs/`). Английские пары — в `docs/en/specs/`, если файл туда положен. Если английского файла в дереве нет, об этом сказано в самом русском тексте, без ссылки в пустоту.
