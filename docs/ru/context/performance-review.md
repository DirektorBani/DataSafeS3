# Обзор производительности

Отдельного отчёта обзора производительности в репозитории нет. Проверка, которая поставляется, — гейт одного узла: простой RSS и время старта этой сборки против `gitverse.ru/direktorbani/datasafe-storage-server:v1.5.0`. Порог — база +10% RSS или +1 с к старту.
