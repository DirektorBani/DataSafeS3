# ADR 0003: путь неизменяемой резервной копии

English: [0003-immutable-backup-path.md](../../../architecture/adr/0003-immutable-backup-path.md).

**Статус:** принято  
**Дата:** 2026-07-10 (принято 2026-07-14, v1.2.0)

## Контекст

Запросы на резервное копирование с защитой от шифровальщика ждут один рабочий путь: Object Lock вместе с версионированием (restic, Kopia, Velero).

## Решение

Закрыть пробелы приёмки и описать версионирование и Object Lock как один сценарий **неизменяемой копии**:

- сценарий EN/RU: `docs/use-cases/*/immutable-backup.md`;
- консоль: `retention_mode` (GOVERNANCE или COMPLIANCE) и приостановка версионирования;
- в v1.2.0 нет многошагового «мастера ради мастера».

Нельзя называть хранение WORM, если Object Lock не включён. Для заявлений Community метаданные блокировки одинаковы на Bolt и PostgreSQL.

## Последствия

Оператор получает честный путь после переноса с MinIO. Полный паритет с AWS Object Lock в объём не входит. Повышение реплики HA и Kafka остаются отдельными ADR.
