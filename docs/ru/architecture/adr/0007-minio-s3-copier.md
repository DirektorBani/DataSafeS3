# ADR 0007: копир объектов MinIO

English: [0007-minio-s3-copier.md](../../../architecture/adr/0007-minio-s3-copier.md).

**Статус:** принято  
**Дата:** 2026-10-14  
**Релиз:** v1.6.0

## Контекст

Нужна команда `storage-cli migrate from-minio`, которая копирует версии, маркеры удаления, Object Lock, метки и пользовательские метаданные и пишет пакет свидетельств PASS/FAIL. ADR 0001 оставлял байты на rclone, чтобы продукт не заявлял импортёр MinIO.

## Решение

Возобновляемый копир S3 в `internal/migrate`, команда `storage-cli migrate from-minio`.

- Состояние — JSONL в `--state` (по умолчанию `./.minio-migrate-state`). Нового драйвера базы нет.
- Версия пропускается, если она есть в файле состояния, если метаданные цели `x-amz-meta-datasafe-source-version` совпали с идентификатором версии источника, или если совпали ETag и размер и не задан `--sse`. SSE меняет ETag, поэтому в этом случае ключ метаданных и есть проверка идемпотентности.
- Версии одного ключа копируются от старых к новым. Текущая версия — последней, чтобы голова цели совпала с источником.
- Операторы политики бакета, которые сервер не умеет проверить, пропускаются с предупреждением и не применяются.
- HTTP 503 `not cluster leader` повторяется. Несколько значений `--target` разбираются через `GET /healthz` и поле `is_leader`.
- Отчёт: `summary.md`, `evidence.json` с верхним полем `verdicts` и `evidence.zip`.
- **Настройки → Миграция** печатает команду с `$SOURCE_ACCESS_KEY` и остальными переменными ключей. Браузер учётные данные источника не получает и не хранит. Локальный `evidence.json` открыть можно.

Чеклист, рецепт rclone и дымовой скрипт из ADR 0001 остаются. Импорт IAM — `storage-cli migrate from-minio iam` того же релиза: пользователи, группы, служебные учётки и политики, которые сервер умеет применить. LDAP и OIDC сообщаются и не импортируются. Секреты MinIO не копируются.

## Последствия

- HEAD и GET отдают `x-amz-meta-*`. Маркеры удаления и составные загрузки эти метаданные сохраняют.
- Пути выполняются по запросу. Простой одиночный узел не запускает копир, клиент Vault и новую метрику.
- DataSafe отдаёт одну страницу версий (копир просит 100000 ключей). Страницы MinIO читаются дальше.
- Прогон на 10 000 объектов, составной объект больше 100 МБ и отказ лидера из трёх узлов остаются приёмкой оператора на MinIO. CI покрывает два процесса DataSafe и, когда образ доступен, один контейнер MinIO с небольшим объектом.
